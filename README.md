# تعلّم الإنجليزية 📚

تطبيق جوّال لتعلّم اللغة الإنجليزية للناطقين بالعربية، مبني بـ **React Native + Expo**، يعمل على **iOS** و **Android** من نفس الكود.

> **إصدار Expo SDK: 54** — مثبّت عمداً ليطابق الإصدار الذي يدعمه تطبيق **Expo Go** في المتاجر (نسخة 54.0.2).
> Expo Go يدعم إصدار SDK واحداً فقط في كل وقت، فلو رفعت المشروع لإصدار أحدث من الذي يدعمه Expo Go
> ستظهر رسالة *"Download the latest version of Expo Go"* ولن يفتح المشروع.
> لا ترفع `expo` لإصدار أعلى إلا بعد نزول تحديث Expo Go الذي يدعمه.

## التشغيل السريع (تجربة التطبيق على جوّالك خلال دقائق)

هذه أسرع طريقة لرؤية التطبيق يعمل على جهازك، بدون أي حساب مطوّر.

### 🪟 على ويندوز — الطريقة الأسهل

بعد فكّ ضغط المجلد، **اضغط مرتين على ملف `START-APP.bat`**.

الملف ينتقل تلقائياً إلى مجلده، يتحقق من وجود Node.js، يثبّت الحزم، ثم يشغّل الخادم ويعرض رمز QR.
لا حاجة لأي أوامر ولا للتنقّل بين المجلدات.

> إن أُغلقت النافذة فوراً، فهذا يعني أن الملف ليس بجانب `package.json` — تأكد أنك فككت ضغط المجلد ولم تفتحه من داخل ملف ZIP.

### أو يدوياً (ماك ولينكس، أو إن فضّلت الأوامر)

افتح الطرفية **داخل مجلد المشروع** — أي المجلد الذي يحتوي على `package.json` — ثم:

```bash
npm install
```

```bash
npx expo start
```

سيظهر لك رمز QR في الطرفية.

> ⚠️ إن ظهرت رسالة `Need to install the following packages: expo@...` فهذا يعني أنك خارج مجلد المشروع
> أو أن `npm install` لم ينجح — لأن `npx` لم يجد نسخة `expo` المحلية فحاول جلبها من الإنترنت.
> تحقق بالأمر `dir package.json` على ويندوز أو `ls package.json` على ماك.

### ٣. افتح التطبيق على جوّالك

| النظام | الخطوات |
| --- | --- |
| **Android** | ثبّت تطبيق **Expo Go** من Google Play، افتحه، واضغط "Scan QR code" ثم امسح الرمز |
| **iPhone / iPad** | ثبّت **Expo Go** من App Store، ثم امسح الرمز بتطبيق **الكاميرا** العادي واضغط على الإشعار |

> يجب أن يكون الجوّال والحاسوب على **نفس شبكة الواي فاي**. إن لم تعمل، جرّب:
> `npx expo start --tunnel`

## بناء تطبيق حقيقي قابل للتثبيت

`Expo Go` مناسب للتجربة فقط. لتحصل على تطبيق مستقل بأيقونته الخاصة يُثبَّت كأي تطبيق آخر، استخدم **EAS Build** (البناء يتم على خوادم Expo — لا تحتاج جهاز Mac).

### 🪟 على ويندوز — الطريقة الأسهل

**اضغط مرتين على ملف `BUILD-ANDROID.bat`** — يقودك خطوة بخطوة: تسجيل الدخول إلى Expo،
ربط المشروع، ثم بناء ملف APK. لا تحتاج Android Studio ولا جهاز Mac ولا أي اشتراك مدفوع.

### أو يدوياً

```bash
npx eas-cli@21 login          # أنشئ حساباً مجانياً على expo.dev
npx eas-cli@21 init           # يربط المشروع بحسابك ويضيف projectId
```

### 🤖 أندرويد — ملف APK للتثبيت المباشر

```bash
npx eas-cli@21 build --platform android --profile preview
```

عند انتهاء البناء ستحصل على رابط تحميل ملف `.apk`. افتح الرابط من جوّالك، حمّل الملف، ثم ثبّته
(قد يطلب منك النظام السماح بـ "التثبيت من مصادر غير معروفة" — هذا طبيعي).

**هذه الطريقة مجانية بالكامل ولا تحتاج أي اشتراك.** يمكنك أيضاً مشاركة الرابط مع أي شخص ليثبّت التطبيق.

### 🍎 آيفون — الخيارات المتاحة

تثبيت التطبيقات على iOS مقيّد من آبل، وأمامك ثلاثة خيارات:

| الخيار | التكلفة | الملاحظات |
| --- | --- | --- |
| **Expo Go** | مجاني | الأسهل — راجع قسم التشغيل السريع أعلاه |
| **حساب مطوّر آبل + TestFlight** | ٩٩ دولاراً سنوياً | تطبيق حقيقي مستقل، ويمكن مشاركته مع حتى ١٠٠ شخص |
| **محاكي iOS على جهاز Mac** | مجاني | للتطوير فقط، لا يعمل على جهاز حقيقي |

للبناء بحساب مطوّر:

```bash
npx eas build --platform ios --profile preview
```

للبناء لمحاكي iOS (يتطلب Mac):

```bash
npx eas build --platform ios --profile ios-simulator
```

## النشر في المتاجر

```bash
# بناء نسخة الإنتاج
npx eas build --platform android --profile production   # ملف .aab لمتجر Google Play
npx eas build --platform ios --profile production       # لمتجر App Store

# الرفع للمتاجر
npx eas submit --platform android
npx eas submit --platform ios
```

**ما تحتاجه:**

- **Google Play**: حساب مطوّر برسوم **٢٥ دولاراً مرة واحدة**
- **App Store**: حساب مطوّر برسوم **٩٩ دولاراً سنوياً**
- **رابط سياسة خصوصية** — جاهزة في `PRIVACY.md`، ارفعها على GitHub Pages أو أي استضافة وضع رابطها
- صور من التطبيق، وصف، تصنيف محتوى، ونموذج Data Safety

قبل النشر، غيّر `bundleIdentifier` و `package` في ملف `app.json` إلى معرّف يخصّك.

## إضافة دروس جديدة

كل المحتوى في ملف واحد: `src/data/lessons.ts`. أضف عنصراً جديداً إلى مصفوفة `LESSONS`:

```ts
{
  id: 'sports',                    // معرّف فريد — لا تغيّره بعد النشر
  title: 'الرياضة',
  titleEn: 'Sports',
  emoji: '⚽',
  level: 'beginner',               // beginner | intermediate | advanced
  words: [
    {
      id: 'sports-football',       // معرّف فريد للكلمة
      en: 'Football',
      ar: 'كرة قدم',
      example: 'I play football every Friday.',
      exampleAr: 'ألعب كرة القدم كل جمعة.',
    },
  ],
  grammar: {
    title: 'عنوان القاعدة',
    body: 'شرح مبسّط بالعربية.',
    examples: [{ en: 'Example sentence.', ar: 'جملة المثال.' }],
  },
}
```

الدرس الجديد يظهر تلقائياً في كل الشاشات: قائمة الدروس، البطاقات، والاختبارات.

> ⚠️ لا تغيّر `id` أي كلمة بعد نشر التطبيق، لأن تقدّم المستخدمين مرتبط بهذه المعرّفات.

## الخصوصية

التطبيق لا يجمع أي بيانات ولا يتصل بأي خادم. كل تقدّمك محفوظ محلياً على جهازك عبر `AsyncStorage`،
ويُحذف عند حذف التطبيق أو بالضغط على "تصفير كل التقدّم" في شاشة *تقدّمي*.
